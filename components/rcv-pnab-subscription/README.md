# Componente `<rcv-pnab-subscription>`
Componente para inscrição na oportunidade PNAB
  
## Propriedades
- *Entity **entity*** - Entidade

### Importando componente
```PHP
<?php 
$this->import('rcv-pnab-subscription');
?>
```
### Exemplos de uso
```HTML
<!-- Utilizaçao básica -->
<rcv-pnab-subscription :entity="entity"></rcv-pnab-subscription>

```
